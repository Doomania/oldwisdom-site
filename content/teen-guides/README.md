# Teen Guide publishing contract

Teen-facing books remain the live teen product surface. This folder reserves a
separate future publishing stream for teen guides, exercises, and companion
material; it is deliberately not read by `scripts/site.py`.

When this stream is activated, it must receive its own manifest schema,
templates, URL namespace, human review criteria, and tests. Do not place a
teen guide in `content/production/` or set `audience: teen` there: that
directory is exclusively for Parent Growth material.

The separation protects the product boundary: Parent Guides help adults see,
understand, reflect, guide, and release; Teen Guides must speak directly to
the teenager and offer an actionable skill without becoming parent education.
