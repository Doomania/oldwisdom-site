# Old Wisdom // Retold

Old Wisdom // Retold is a Teen Growth Platform with separate teen-facing
Playbooks and a parent-facing Parent Growth layer.

## Core surfaces

**Playbook**:
A teen-facing book that turns classic wisdom into practical strategies. It is a
tool for the teen, never parent education.
_Avoid_: Parent manual, parenting programme

**Parent Hub**:
The parent-facing collection of practical guides that helps adults support a
teen's growth without taking ownership away from them.
_Avoid_: Parenting blog, sales funnel

**Parent Guide**:
A publishable Parent Hub item that addresses one concrete concern through a
primary Parent Growth Journey stage.
_Avoid_: Blog post, content asset

**Parent Growth Journey**:
The ordered functions SEE, UNDERSTAND, REFLECT, GUIDE, and RELEASE. It helps a
parent move from observation to support while returning ownership to the teen.

**Release**:
The deliberate return of an appropriate decision, consequence, or next move to
the teen as their judgment and capability grow. It is not withdrawal or lack of
support.

## Publishing

**Publishing Bundle**:
The complete, review-gated source package for one Parent Guide and its channel
derivatives: article, evidence, Pinterest campaign, and optional video assets.

**Pinterest Campaign**:
The reviewed pin titles, descriptions, destinations, and attribution metadata
within a Publishing Bundle. It preserves the established UTM convention.

**Hermes**:
The publishing actor that creates and updates Publishing Bundles. Hermes does
not edit templates, application logic, schema, or generated site files.

**Next Step**:
An optional, explicitly chosen action after a Parent Guide. It can be another
guide, reflection, quiz, download, relevant Playbook, or no action.
_Avoid_: Default funnel, mandatory product CTA
